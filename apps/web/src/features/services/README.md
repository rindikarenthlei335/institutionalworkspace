# Add-on Service Requests (`@eduportal/web/features/services`)

Enables schools to request assisted digital services (Google Search Console indexation, Google Maps business verification, SEO Bundles, White-label Mobile Apps) with automated Pro Tier zero-cost benefits.

## Modules
- **School Catalog (`ServiceCatalogView`)**: Lists add-on service offerings, checks tenant plan, calculates pricing (₹0 on Pro tier), and captures service requests.
- **Platform Owner Queue (`/platform/services`)**: Full triage workflow for platform operators: assignment, in-progress tracking, and completion proof delivery.
