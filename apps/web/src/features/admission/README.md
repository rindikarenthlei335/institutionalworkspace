# Online Admission & Application Review Module

## Purpose
Public online student application form with DPDP consent, public status tracking by Application No, admin application review queue, and convert-application-to-student workflow.

## Routes
- Public: `/admission`, `/admission/status`
- Admin: `/admin/admissions`

## Tables
`admission_settings`, `applications`, `application_documents`, `application_status_history`, `students`, `guardians`, `invoices`.
