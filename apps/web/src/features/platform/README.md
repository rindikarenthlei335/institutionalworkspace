# SaaS Platform Owner Panel Feature Module

## Purpose
Provides platform-level administration for onboarding schools, managing multi-tenant subscriptions, auditing admin impersonations, configuring plan feature overrides, tracking SaaS MRR, and managing domain & service requests.

## Routes
- `/platform/tenants`
- `/platform/plans`
- `/platform/domains`
- `/platform/services`
- `/platform/billing`

## Tables
`tenants`, `tenant_domains`, `plans`, `plan_features`, `tenant_feature_overrides`, `domain_requests`, `service_requests`, `audit_logs`, `file_objects`.
