# Daily Attendance & Alerts / Kallam Chhinchhiah leh Hriattirna

## English (en)
### How to Record Attendance and Track Absentees
1. **Marking Attendance**: In **Admin -> Attendance**, select Class and Section to mark Present, Absent, Late, or Excused with single-click bulk tools.
2. **Low-Attendance Thresholds**: The system monitors cumulative attendance. Any student falling below the 75% threshold is flagged with an alert for parent notifications.

- `/admin/attendance`

1. **Kallam Chhinchhiah**: **Admin -> Attendance** ah Pawl leh Section thlangin Kal, Kallo, Tlai zung zung rawh.
2. **75% Tlinglo Hriattirna**: Kallam za zela 75% tlinglo te chu system-in automatic-in nu-leh-pa hriattir turin a chhut chhuak thin.
