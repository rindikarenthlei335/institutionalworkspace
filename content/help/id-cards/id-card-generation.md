# ID Card Generator / ID Card Siama Print Dan

## English (en)
### How to Generate CR80 ID Cards
1. **Access**: Go to **Admin -> ID Card Generator**.
2. **Preflight**: Verify photo completeness before printing.
3. **Printing**: Generate single CR80 plastic card dimensions or 8-up A4 printable sheets complete with institutional crest, barcodes, and public QR verification endpoints.

- `/admin/id-cards`
